1) 이 폴더에서: python -m http.server 8000   (Windows: py -m http.server 8000)
2) 크롬/엣지에서 http://localhost:8000 접속 → 카메라 허용 → F 키 또는 ⛶ 버튼으로 전체화면
단축키: F 전체화면, C 카메라 미리보기, M 마이크(언어 감지) 켜기/끄기
마이크: M을 누르면 Whisper 음성 모델(약 80~150MB, 최초 1회 다운로드 후 브라우저 캐시)을 받고,
  말을 걸면 언어를 감지해 그 언어로 말풍선 글씨 인사를 보여줍니다(음성 출력 없음): 한국어/English/中文(简体)/粵語(繁體)/日本語
  광동어는 인식된 문장에 광동어 특유 글자(係,嘅,唔 등)가 있을 때만 구분됩니다.
인터넷 필요(라이브러리·모델 CDN 로드). 모델 오류 시에도 얼굴 인식 기능은 그대로 동작합니다.

[대화]
- 마이크를 켜고 말하면 한/영/中/粵/日 일상 대화(인사·질문·농담·웃음·위로 등)에 글씨+표정으로 답합니다. 대화 문구는 dialogue.js에서 수정.
- 사람이 있고 20초 조용하면 먼저 질문합니다. 이름을 말하면 기억합니다.
- 시험: 주소 뒤에 ?say=ㅋㅋㅋ&lang=ko
- Grok 연결(선택): server/README.md 참고
- 눈동자가 사람(얼굴, 없으면 움직임)을 따라갑니다. 여러 명이면 번갈아 봅니다. 점검: 주소 뒤에 ?debug=1
- 동작 인식: 손 흔들기, 손가락 하트, 머리 위 큰 하트, 엄지척, 브이, 박수, 손가락으로 가리키기, OK, 손바닥 멈춤, 만세, 얼굴 가리고 까꿍. 시험: ?gesture=bigheart

[클라우드 음성 인식 (선택, 기본 꺼짐)]
- 기본은 기기 안의 Whisper로 받아 적어요. 더 정확한 xAI 음성 인식(grok-voice-transcribe-2.0, 약 $0.10/시간)을 쓰려면:
  1) server/ 프록시를 배포 (환경변수 XAI_API_KEY — Grok 대화와 같은 키). 주소 예: https://tv-character-api.onrender.com/stt
  2) config.js 의 STT_ENDPOINT 에 그 주소 입력 (시험: 주소 뒤에 ?stt=https://.../stt)
- 켜져 있으면 Whisper 모델을 미리 받지 않고, 클라우드가 6초 안에 답하지 않거나 오류가 나면 그때 Whisper를 받아 대신 사용해요.
- 다른 OpenAI 호환 서비스: 서버 환경변수 STT_URL, STT_MODEL, STT_KEY 로 변경.
